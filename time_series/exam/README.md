# Stock Forecast Telegram Bot

Интеллектуальный Telegram-бот для прогнозирования цен акций с использованием современных методов машинного обучения.

---

## Описание

Бот анализирует исторические данные акций с Yahoo Finance и строит прогноз на 30 дней вперед. Система автоматически сравнивает три модели машинного обучения, выбирает наиболее точную и предоставляет торговые рекомендации с расчетом потенциальной прибыли.

**Disclaimer:** Проект создан в образовательных целях и не является финансовым советом.

## Возможности

### Основной функционал
- 📊 **Прогнозирование на 30 дней** - фиксированный период для всех анализов
- 🤖 **Три модели ML** - автоматический выбор лучшей из Random Forest, Prophet и Chronos
- 📈 **Свечные графики** - профессиональная визуализация с историческими данными
- 💰 **Торговые сигналы** - автоматическое определение точек покупки/продажи
- 💵 **Расчет прибыли** - симуляция стратегии с заданным капиталом

### Интерфейс
- Удобный выбор акций через inline-кнопки
- Категории тикеров: Tech, Finance, Healthcare, Retail, Energy, Industrial
- Поиск тикеров по названию через команду `/get_tickers`
- Главное меню для быстрого доступа к функциям

Создайте файл `.env`:
```env

```

```bash
python bot.py
```

## Модели машинного обучения

### Random Forest
- **Тип:** Классический ML
- **Особенности:** Быстрое обучение, использует лаговые признаки
- **Проверка:** Автоматическая фильтрация "плоских" прогнозов

### Prophet
- **Тип:** Статистическая модель от Meta
- **Особенности:** Хорошо улавливает тренды и сезонность
- **Применение:** Эффективен для стабильных акций

### Chronos
- **Тип:** Предобученная трансформерная модель от Amazon
- **Особенности:** Zero-shot прогнозирование, 20 сэмплов для усреднения
- **Преимущества:** Наиболее точные прогнозы в большинстве случаев

**Выбор модели:** Система автоматически выбирает модель с наименьшим RMSE, учитывая штрафы за плоские прогнозы.

## Визуализация

### Свечной график
- Зеленые свечи - рост цены
- Красные свечи - падение цены
- Каждая свеча показывает Open, High, Low, Close

### Прогноз
- Черная пунктирная линия
- Плавное соединение с последней ценой закрытия

### Торговые сигналы
- Зеленые треугольники вверх (▲) - покупка
- Оранжевые треугольники вниз (▼) - продажа
- Маркеры с белой окантовкой для четкости

## Логирование

Все запросы сохраняются в `logs/requests_log.csv`:

| Поле | Описание |
|------|----------|
| user_id | Telegram ID пользователя |
| timestamp | Время запроса |
| ticker | Символ акции |
| amount | Сумма инвестиции |
| forecast_days | Период прогноза (всегда 30, по условию задания) |
| best_model | Выбранная модель |
| metric_value | RMSE лучшей модели |
| profit | Прибыль в процентах |

## Настройки

### Период исторических данных

По умолчанию: 2022-2024. Можно изменить в `config.py`:

```python
START_DATE = '2022-01-01'
END_DATE = '2024-01-01'
```

### Параметры моделей

**Random Forest:**
```python
RF_N_ESTIMATORS = 100
RF_MAX_DEPTH = 10
LAG_WINDOW = 60
```

**Chronos:**
```python
CHRONOS_MODEL = "amazon/chronos-t5-tiny"
CHRONOS_SAMPLES = 20
```

## Ограничения

1. **Данные:** Зависимость от доступности Yahoo Finance API
2. **Время анализа:** 30-90 секунд на один запрос
3. **Прогноз:** Фиксированный период 30 дней
4. **Точность:** Модели не гарантируют будущую доходность
5. **Ресурсы:** Модель Chronos требует ~100MB на первый запуск
