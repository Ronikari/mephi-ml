# Проект по Reinforcement Learning: Обучение агента на среде LunarLander-v2

## Описание проекта

Данный проект демонстрирует применение алгоритмов обучения с подкреплением (RL) из библиотеки stable-baselines3 для решения задачи посадки космического корабля на Луну в среде **LunarLander-v2** из Gymnasium.

### Цель проекта

Продемонстрировать умение применять готовые RL-алгоритмы для решения стандартной задачи, провести контролируемые эксперименты и проанализировать их влияние на обучение.

## Структура проекта

```

├── train.py          # Основной скрипт обучения агента
├── experiments.py    # Скрипт для проведения контролируемых экспериментов

```

## Использование

### Базовое обучение агента

Обучить базового агента PPO:

```bash
python train.py
```

Это создаст:
- Обученную модель в `models/ppo_final.zip`
- Логи обучения в `logs/ppo/`
- Лучшую модель в `models/ppo_best/`

### Проведение экспериментов

Запустить все контролируемые эксперименты:

```bash
python experiments.py
```

Это выполнит:
- **Эксперимент 1**: Сравнение алгоритмов PPO и A2C
- **Эксперимент 2**: Влияние гиперпараметра gamma на обучение

Результаты будут сохранены в:
- `experiments/models/` - обученные модели
- `experiments/logs/` - логи обучения
- `experiments/plots/` - графики сравнения

### Оценка агента

Оценить обученного агента на нескольких эпизодах:

```bash
python evaluate.py models/ppo_final.zip 20
```

Это создаст:
- Статистику оценки в `results/evaluation_stats.csv`
- Видео эпизодов в `videos/evaluation/`

### Создание анимации

Создать анимацию работы агента:

```bash
python visualize.py animate models/ppo_final.zip
```

## Описание экспериментов

### Эксперимент 1: Сравнение алгоритмов PPO и A2C

**Гипотеза**: PPO должен показать более стабильное обучение и лучшие результаты благодаря механизму clipping, который ограничивает слишком большие изменения политики и обеспечивает более плавное обучение.

**Методология**:
- Оба алгоритма обучаются на одинаковых условиях (seed=42, gamma=0.99)
- Используются стандартные гиперпараметры для каждого алгоритма
- Оценка производится каждые 10000 шагов на 10 эпизодах

**Ожидаемые результаты**:
- PPO должен показать более стабильную кривую обучения
- PPO должен достичь более высоких финальных наград

### Эксперимент 2: Влияние гиперпараметра gamma на обучение

**Гипотеза**: При увеличении gamma (коэффициент дисконтирования) агент будет больше учитывать долгосрочные награды и лучше планировать свои действия, что должно улучшить финальные результаты. Однако слишком высокий gamma может замедлить обучение из-за увеличения дисперсии оценок.

**Методология**:
- Тестируются значения gamma: [0.90, 0.95, 0.99, 0.999]
- Все остальные гиперпараметры остаются одинаковыми
- Используется алгоритм PPO

**Ожидаемые результаты**:
- Оптимальное значение gamma находится в диапазоне 0.95-0.99
- Слишком низкий gamma (0.90) приводит к недостаточному планированию
- Слишком высокий gamma (0.999) может замедлить обучение

## Параметры обучения

### Базовые параметры

- **Seed**: 42 (для воспроизводимости)
- **Общее количество шагов**: 500,000
- **Частота оценки**: каждые 10,000 шагов
- **Количество эпизодов для оценки**: 10

### Гиперпараметры PPO

- **Learning rate**: 3e-4
- **Batch size**: 64
- **N steps**: 2048
- **N epochs**: 10
- **Gamma**: 0.99
- **GAE lambda**: 0.95
- **Clip range**: 0.2
- **Entropy coefficient**: 0.01
- **Value function coefficient**: 0.5

### Гиперпараметры A2C

- **Learning rate**: 7e-4
- **N steps**: 5
- **Gamma**: 0.99
- **GAE lambda**: 0.95
- **Entropy coefficient**: 0.01
- **Value function coefficient**: 0.5
